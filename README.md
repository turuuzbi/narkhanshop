# Нархан дэлгүүр — онлайн дэлгүүр + админ (демо)

**Нархан** (Instagram [@narkhan_shop](https://instagram.com/narkhan_shop)) — Европоос ирсэн H&M-ийн жинхэнэ дотуур хувцас, унтлагын хувцас зардаг дэлгүүрт зориулсан, утсан дээр гар хүрч үзэж болох **демо** вэбсайт. Instagram DM-ээр гараар захиалга авч байсныг вэбсайт хэрхэн хөнгөвчлөхийг харуулна.

> ⚠️ Энэ бол демо. Админ хэсэгт нэвтрэх эрх шаардахгүй, төлбөр (Storepay, Pocket Zero, данс) нь зөвхөн дүрслэл. Албан ёсны сайт биш — *Demo by Turuu, not the official site.*

## Юу багтсан бэ

**Дэлгүүр (үйлчлүүлэгчийн тал)**
- Нүүр хуудас: лого, уриа, «Хэмжээгээр сонгох» (XS–XL), ангилал, шинэ ирэлт, урамшууллын баннер, онцлох бараа, давуу талууд (H&M оригинал · бэлэн бараа · хүргэлт 5,000₮ · Storepay / Pocket Zero)
- **Хэмжээ олох**: жин (+ өндөр) оруулахад Нарханы хэмжээний хүснэгтээр хэмжээ санал болгож, «Миний хэмжээний бүх бараа» руу шилжүүлнэ
- Каталог: ангилал, загвар, бэлэн байгаа хэмжээ, өнгө, үнэ, хямдрал, шинэ, эрэмбэ, хайлт. Шүүлтүүр URL-д хадгалагдана (линкээр хуваалцаж болно). Утсан дээр доороос гарч ирэх шүүлтүүр
- Барааны хуудас: зургийн цомог, дууссан хэмжээг идэвхгүй болгох, «Сүүлийн 2 ширхэг», өнгө сонгох, «Storepay-р 4 хувааж: … × 4», хэмжээний хүснэгт, доод талд наалдсан «Сагслах» товч, төстэй бараа, саяхан үзсэн
- Сагс (drawer + хуудас), хэмжээ/тоо засах, урамшууллын мэдэгдэл (Sale L, XL бэлэг)
- Нэг хуудастай захиалга: 8 оронтой утасны шалгалт, УБ-ын дүүрэг, хороо, хаяг, энгийн/шуурхай хүргэлт, Storepay / Pocket Zero / данс → захиалгын дугаар (NK-1013 г.м.) ба дараагийн алхмууд
- Нэмэлт: хадгалсан бараа (♡), саяхан үзсэн, «DM-ээр захиалах», «Залгах 95601111», хэмжээний заавар, хүргэлт & төлбөрийн мэдээлэл

**Админ — `/admin`**
- Хянах самбар: өнөөдрийн захиалга, орлого (өнөөдөр / 7 хоног), төлөв тус бүрээр, дуусаж буй хэмжээ, их борлуулалттай бараа, 7 хоногийн орлогын график
- Захиалга: төлөвөөр шүүх, хайх, дэлгэрэнгүй, төлөвийн шат **Шинэ → Баталгаажсан → Хүргэлтэнд гарсан → Хүргэгдсэн / Цуцалсан** (цуцлахад үлдэгдэл буцна), **«Жолоочид хуулах»** товч
- ⭐ **DM захиалга**: Instagram/Facebook-ийн захиалгыг утсаар 30 секундэд бүртгэх. DM-ийн текстийг paste хийхэд нэр, утас, дүүрэг (БЗД, СБД, ХУД… товчлол ч таньдаг), хороо, хаяг автоматаар бөглөгдөнө
- Бараа: хайх/шүүх, нэмэх/засах/устгах/хуулбарлах, хэмжээ тус бүрийн үлдэгдэл, үнэ + хямдралтай үнэ, Шинэ/Онцлох, зураг оруулах
- Үлдэгдэл: бараа × хэмжээ хүснэгт дээр шууд засах, дуусаж буйг тодруулна
- Ангилал & загвар, Урамшуулал (нэмэх/засах/асаах-унтраах), Тохиргоо (утас, хүргэлтийн үнэ, төлбөрийн нэрс)
- Захиалгыг CSV-ээр татах (Excel-д кирилл зөв харагдана), «Демо өгөгдлийг сэргээх»
- Утсан дээр доод цэс, компьютер дээр хураагддаг хажуугийн цэс

## Суулгах, ажиллуулах

Шаардлага: **Node.js 20+** (22 дээр шалгасан), npm.

```bash
npm install && npx prisma migrate dev && npm run seed && npm run dev
```

Дараа нь http://localhost:3000 (дэлгүүр) ба http://localhost:3000/admin (админ) нээнэ.

- `npm install` — сангууд суулгаж, Prisma client үүсгэнэ (интернэт хэрэгтэй цорын ганц алхам)
- `npx prisma migrate dev` — `prisma/dev.db` SQLite өгөгдлийн сан үүсгэнэ
- `npm run seed` — 33 бараа, 4 ангилал, 12 жишээ захиалга, 2 урамшуулал үүсгэнэ (дахин ажиллуулахад анхны байдалд орно)
- `npm run dev` — хөгжүүлэлтийн сервер

Бусад: `npm run build && npm start` (production), `npm run typecheck`.

`.env` файлд зөвхөн `DATABASE_URL="file:./dev.db"` байгаа (нууц зүйлгүй). Фонт, зураг бүгд репод байгаа тул `npm install`-ийн дараа интернэтгүй ажиллана.

## Үйлчлүүлэгчид үзүүлэх демо (утсаар)

Утсан дээрээ (эсвэл Chrome DevTools-ийн 390px өргөнтэй горимд) дараах дарааллаар үзүүлнэ:

**А. Хэмжээгээ олоод M хэмжээг шүүх**
1. Нүүр хуудсыг нээнэ — 5 секундэд дэлгүүрийн өнгө төрх, бэлэн бараа, хүргэлт, хувааж төлөх боломж харагдана.
2. **«Хэмжээгээ олох»** → жин `65` гэж бичнэ → **M** санал болгоно.
3. **«M хэмжээтэй бүх бараа»** → каталог зөвхөн M нь бэлэн байгаа барааг харуулна (Instagram-ийн highlight-аар хайхаас хамаагүй хурдан).

**Б. Бараа сонгоод захиалах**
1. Аль нэг бараа нээнэ — M хэмжээ автоматаар сонгогдсон, дууссан хэмжээ идэвхгүй, «2 үлдсэн» гэх мэт харагдана.
2. **«Сагсанд нэмэх»** → сагс нээгдэнэ → **«Захиалах»**.
3. Нэр, утас (8 орон), дүүрэг, хороо, хаягаа бөглөж, **Шуурхай хүргэлт** + **Storepay** сонгоод **«Захиалах»**.
4. Захиалгын дугаар (ж: **NK-1013**) ба дараагийн алхмууд гарна. DM-ээр нэг ч мессеж бичилгүйгээр захиалга орлоо.

**В. Админд захиалгаа харах**
1. `/admin` → хянах самбарт шинэ захиалга, өнөөдрийн орлого шууд харагдана.
2. Захиалгыг нээгээд **«Баталгаажуулах»** → **«Хүргэлтэнд гаргах»** дарна.
3. **«Жолоочид хуулах»** → нэр, утас, хаяг, бараа, авах дүнтэй цэвэр текст хуулагдана — жолооч руу шууд илгээнэ.

**Г. DM захиалга, үлдэгдэл, сэргээх**
1. Доод цэсний голын **⚡ DM захиалга** → **«Жишээ»** (эсвэл жинхэнэ DM-ээ paste хийх) → нэр, утас, дүүрэг, хороо, хаяг автоматаар бөглөгдөнө.
2. Барааны хэмжээн дээр дарж нэмээд **«Захиалга хадгалах»** — үлдэгдэл автоматаар хасагдана.
3. **Үлдэгдэл** цэс → дурын нүдэн дээр тоо засаад Enter → хадгалагдана.
4. **Тохиргоо → «Демо өгөгдлийг сэргээх»** → баталгаажуулахад бүх өгөгдөл анхны байдалд орно.

## Vercel дээр байршуулах

### 1. Шууд ажиллана — демо горим
Репог Vercel-д холбоход нэмэлт тохиргоогүйгээр ажиллана. Vercel-ийн файлын систем зөвхөн уншигддаг тул өгөгдлийн сан тохируулаагүй үед апп **демо горимд** ажиллана: сервер асах бүрт `/tmp` дотор шинэ SQLite өгөгдлийн сан үүсгэж, демо өгөгдлөөр дүүргэнэ (`src/instrumentation.ts` → `src/lib/demo-db.ts`, ~0.2 сек).

- Захиалга, засвар ажиллана, гэхдээ **түр хадгалагдана**: Vercel серверийг унтраагаад дахин асаахад (хэсэг хугацаанд хэн ч ороогүй үед) анхны демо өгөгдөл рүү буцна.
- Админы дээд мөрөнд «Өгөгдөл түр хадгалагдана…» гэж харагдана.

### 2. Өгөгдлийг байнга хадгалах — Neon Postgres (2 минут)
1. Vercel → **narkhanshop** project → **Storage** → **Create Database** → **Neon** (Serverless Postgres, үнэгүй) → бүс сонгоод (ж: Singapore) үүсгэнэ.
2. **Connect Project** → narkhanshop, бүх орчин (Production, Preview, Development) → Connect. `DATABASE_URL`, `DATABASE_URL_UNPOOLED` зэрэг хувьсагч автоматаар нэмэгдэнэ.
3. **Deployments → хамгийн сүүлийнх → Redeploy.**

Build үед `scripts/prisma-build.mjs` Postgres-ийн URL-ыг илрүүлээд: `prisma/schema.prisma`-ийн Postgres хувилбарыг үүсгэж, хүснэгтүүдийг үүсгэнэ (`prisma db push`), өгөгдлийн сан хоосон бол **нэг удаа** демо өгөгдлөөр дүүргэнэ. Дараагийн deploy-ууд өгөгдлийг устгахгүй. Кодонд өөрчлөлт хийх шаардлагагүй, локал хөгжүүлэлт SQLite-аараа үлдэнэ.

### 3. Зураг оруулах (Vercel Blob)
Админаас оруулсан зураг Vercel дээр `/tmp`-д түр хадгалагдана. Байнга хадгалахын тулд Vercel → Storage → **Blob** үүсгэж project-доо холбоно (`BLOB_READ_WRITE_TOKEN` нэмэгдэнэ), `npm i @vercel/blob` хийгээд `src/app/actions/admin.ts` доторх `saveUploads()`-д `fs.writeFile`-ийн оронд:
```ts
import { put } from "@vercel/blob";
const blob = await put(`products/${name}`, f, { access: "public" });
urls.push(blob.url);
```
`next.config.ts`-д `images.remotePatterns: [{ protocol: "https", hostname: "*.public.blob.vercel-storage.com" }]` нэмнэ.

### 4. Жинхэнэ ашиглалтаас өмнө
`/admin`-д нэвтрэх эрх (ж: Auth.js эсвэл `src/proxy.ts`-д нууц үгийн шалгалт) заавал нэмнэ.

## Техник

Next.js 16 (App Router, Turbopack) · TypeScript (strict) · Tailwind CSS 4 · Prisma 6 + SQLite · Server Actions · Zod · Zustand (localStorage) · next/font (local) · next/image · lucide-react.

- Үнэ, урамшуулал, хүргэлтийн төлбөрийг захиалах үед **сервер дээр дахин тооцоолно** (client-ийн үнэд итгэхгүй).
- Үлдэгдэл хасахдаа нөхцөлтэй update (`stock >= qty`) ашигладаг тул сүүлийн ширхэгийг 2 хүн зэрэг авч чадахгүй; аль нэг мөр амжилтгүй бол бүх захиалга буцна. Цуцлахад үлдэгдэл буцаж нэмэгдэнэ.
- Шалгасан: `npm run build` алдаагүй, TypeScript алдаагүй, демо сценари (А–Г) 390px дээр консолын алдаагүй — локал SQLite, Vercel-ийн демо горим, PostgreSQL 16 гурван горимд. Lighthouse mobile — нүүр: Performance 90–96 / Accessibility 100, барааны хуудас: 93 / 100.
